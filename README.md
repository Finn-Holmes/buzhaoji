# 不着急

> 关于教务系统课表导入：本人目前只使用过本校的强智教务系统，对其他教务系统的使用与适配经验有限，欢迎大家反馈问题、提交适配代码，一起完善更多学校和教务系统的课表导入支持。

不着急是一款面向学生的 Android 课表与任务清单应用，将课程、任务与生活安排放在一起。界面与核心交互参考滴答清单，任务、清单、课表、设置与课程变更全部保存在本机。提醒预先登记给 Android 系统，支持普通进程退出后的唤醒，并提供权限、后台限制与通知显示的检查入口。

## 当前可用功能

- “今天”时间线：合并当天课程与任务，并突出下一节课。
- 日历与课表：滴答式月历可左右滑动翻月、选择日期并查看当天任务/课程；一键切换周课表，左右滑动切周，同名课程固定使用同一颜色、不同课程优先使用不同颜色，并支持单双周、起止周、整学期编辑、单周停课、临时调课与恢复。
- 课表导入：教务网导入为主入口，可选学校或填写自定义教务地址，在校方页面自行登录并打开课表后确认导入；图片导入会离线识别星期网格、节次、周次和课程块，失败时回退到 OCR 文字校对，CSV/制表符文本仍作为备用方式。
- 教务适配：内置学校搜索目录与自定义学校地址；中国石油大学（华东）强智课表已实测验证，其他学校会自动依次尝试强智、正方、URP、青果与保守通用表格解析。未验证学校会明确显示“自动识别 · 试验性”，识别结果可逐项编辑、删除，并选择覆盖或合并到当前课表。
- 任务清单：新建、编辑、完成、删除，以及今天/即将截止/已完成筛选；输入时会实时高亮识别到的时间词，日期入口提供日期、时间段、全天、提醒和重复设置。
- 可选功能模块：在“设置 → 功能模块”按需启用四象限、番茄专注、习惯打卡、倒数纪念日与搜索。
- 四象限：根据任务优先级和截止日期自动归类，并可从任一象限直接新建带默认属性的任务。
- 番茄专注：15/25/45 分钟计时、正计时、任务关联和本地专注统计。
- 习惯打卡：周日期栏、每日打卡、连续天数、自定义图标与低功耗系统提醒。
- 倒数纪念日：倒数日、纪念日、生日、节日、每年重复和提前提醒。
- 中文时间识别：例如“明晚八点交实验，提前两小时提醒”或“下周五 19:30 复习”，识别结果会在输入框内以蓝色实时标记。
- 系统提醒：精确闹钟、Doze 唤醒、通知内完成/延后、开机和时区变化后恢复。
- 桌面小组件：下一节课、地点和今日任务。
- 滴答式本地设置页：集中管理学期日期、提醒权限、默认提前时间、课表导入与本地数据概览。
- 提醒健康检查与 30 秒测试提醒。

## 安装测试版

当前源码版本：`0.8.3-android-reminders`。按下方构建步骤生成调试 APK，输出位于 `app/build/outputs/apk/debug/app-debug.apk`。

安装后请在“设置 → 声音、提醒与通知”中完成两项授权：

1. 允许通知。
2. 允许“闹钟和提醒”精确权限。

然后点击“30 秒后台定时测试”，分别验证返回桌面、熄屏和划走应用后的提醒。系统闹钟支持普通进程退出后的唤醒；手机的后台限制、通知类别、勿扰和锁屏设置仍可能影响提醒效果，可展开“后台提醒检查”排查。Android 的“强行停止”会阻止提醒，重新打开后会恢复登记。完整机制与验证范围见 [docs/RELIABLE_REMINDERS.md](docs/RELIABLE_REMINDERS.md)。

## 本地构建

项目支持 Android 8.0 及以上系统。构建使用 JDK 21、Android SDK 36、Gradle 9.5 和 Android Gradle Plugin 9.3。安装 Android Studio 并配置 SDK 后，将本地 SDK 路径写入 `local.properties`（该文件不提交）：

```properties
sdk.dir=C:/Users/your-name/AppData/Local/Android/Sdk
```

Windows：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

macOS / Linux：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

产品范围与后续路线见 [`docs/PRODUCT.md`](docs/PRODUCT.md)，详细进度见 [`docs/IMPLEMENTATION_CHECKLIST.md`](docs/IMPLEMENTATION_CHECKLIST.md)。

教务导入架构参考了 [WakeUp CourseAdapter](https://github.com/YZune/CourseAdapter) 和 [拾光课程表适配仓库](https://github.com/XingHeYuZhuan/shiguang_warehouse) 的公开实现与适配经验；本项目使用自己的统一数据结构、安全边界和内置解析代码。

## 当前边界

- 网页和截图解析均在设备本地完成。App 不读取登录表单，只有用户点击“确认导入”后才读取当前课表 DOM；目前只有 UPC/强智经过真实页面回归，其余目录项是自动识别入口，不代表已经验证兼容。
- 教务网导入确认后会要求校准学期第一周；网页只提供“第几周上课”时，不会再把导入当天默认当成第一周。
- 产品明确不实现账号同步；本地备份/恢复、专注计时跨进程恢复和重复任务的下一次自动生成仍待完成。
- 目前只有 Android 版本；iOS 版本将在 Android 的核心交互和数据模型稳定后评估。
