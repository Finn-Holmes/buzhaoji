# 0.8.0 · 今天的节奏

本次设计以深梅紫、暖桃色和柔和光团建立辨识度。当前界面没有重新引入旧乌龟形象。

## 新功能

- 今天页的光团有呼吸、完成时亮起和收工后休息状态；轻点可得到简短回应，动效可以关闭。
- “今天收工”汇总当天完成、专注和习惯打卡，保存最多 280 字的本地回顾；可以重新开启今天。
- 收工不会改变任务截止时间和提醒。未完成任务可展开并进入编辑。
- “一周足迹”支持切换历史周、查看每日记录和回顾。分享生成本地 PNG，通过系统分享面板由用户自行选择去向；图片不包含任务名和回顾文字。

## 小组件

| 小组件 | 本次调整 |
| --- | --- |
| 今天 | 可滚动任务列表、更大的完成热区、任务编辑、桌面快速添加、课程与设置同步 |
| 习惯 | 鼠尾草色卡片、七日轨迹、直接打卡与取消、选择习惯、防重复点击 |
| 倒数 | 暖纸色卡片、过去/今天/未来状态、正数天数、选择事件 |
| 倒数列表 | 可滚动完整事件列表，自动优先展示今天与未来的日子 |
| 统计 | 一周柱状轨迹、真实完成历史、点击进入一周足迹 |
| 番茄 | 原生计时、开始/暂停、完成记录去重、只改主题不会重置计时、倒计时显示修正 |

同步更新小组件选择器和配置页预览。课表与紧凑小组件未重新设计。

倒数与统计卡的最小高度设为 130dp，给数字、状态和桌面宿主留足空间，避免缩小后截断底部文字。

## 数据与兼容

- Room 数据库从 5 升级到 6，新增每日回顾和任务完成事件表；保留既有数据。
- 完成事件在循环任务进入下一次和任务删除后仍保留，普通任务取消完成时同步撤销对应记录。
- 升级前仍存在的已完成任务可以补入历史；旧版本未保存的循环任务历次完成记录无法追溯。
- 调试专用 WidgetQaActivity 和测试数据辅助入口仅存在于 debug source set。
