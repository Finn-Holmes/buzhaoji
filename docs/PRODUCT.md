# 序间产品说明

序间是一款面向学生的离线优先 Android 应用，将课程表、作业、考试和普通待办放在同一条时间线上。核心目标不是让应用常驻后台，而是把提醒提前登记给 Android 系统，在应用退出、进程回收或设备休眠时仍能准时通知。

## 第一版原则

- 免费核心功能完整，不人为限制课表、任务、提醒和小组件数量。
- 本地优先，无账号也能使用；未来的同步是可选能力。
- 所有时间识别都可见、可修改，绝不静默猜测。
- 课程、任务和提醒使用同一套时间模型。
- 不常驻后台，不周期性轮询；只在必要时由系统短暂唤醒。
- 参考滴答清单的高效交互，但使用独立的品牌、视觉和实现。

## 信息架构

1. 今天：按时间排序展示课程、任务和考试，突出下一件事。
2. 课表：按周次与星期查看课程，支持单双周、临时调课和停课。
3. 任务：收集箱、今天、即将截止、已完成，以及课程关联任务。
4. 设置：学期、节次、默认提醒、通知权限与提醒健康检查。

## 核心用户故事

- 我导入一张教务系统课表截图，检查识别结果后一次性保存整学期课程。
- 我输入“周五晚上八点交数据库实验，提前两小时提醒”，应用自动拆分标题、截止时间和提醒时间。
- 我划掉应用并锁屏，课程开始前仍收到普通横幅通知。
- 我在桌面小组件直接看到下一节课和今日未完成任务。
- 我重启手机后，不需要打开应用也不会丢失已登记的未来提醒。

## 版本路线

### 0.1 本地 MVP

- 今天、课表、任务、设置四个主入口
- 课程与任务本地数据库
- 中文时间识别
- 精确提醒、延后、完成、开机恢复
- 下一节课与今日任务小组件

### 0.2 课表导入

- 手动录入与批量粘贴
- 图片选择、裁剪、OCR、表格结构解析
- 导入校对、冲突检测、课程合并

### 0.3 同步与备份

- 本地导出与恢复
- 可选端到端加密同步
- 日历订阅与 ICS 导入导出
